# Палеослов

«Палеослов» — локальный цифровой скрипторий для изучения исторических славянских текстов. Основной способ установки для пользователя — готовый DMG: приложение, OCR-движок, модели и библиотеки уже находятся внутри. Устанавливать Python, Homebrew, Ollama или скачивать модели отдельно не нужно.

## Скачать и запустить

1. Откройте вкладку **Releases** и скачайте `Палеослов-0.1.1-macOS-arm64.dmg`.
2. Откройте DMG и перетащите «Палеослов» в папку «Программы».
3. Запустите приложение. При первом запуске macOS может попросить подтвердить открытие приложения, поскольку выпуск не подписан сертификатом Developer ID и не notarized.

Сборка предназначена для Mac с Apple Silicon. Все локальные функции работают без сети. Интернет нужен только для поиска свежих библиографических записей.

## Что работает в этой версии

- Открытие изображений, многостраничных TIFF и сканированных PDF; страницы хранятся локально.
- OCR рукописных строк встроенным Kraken/Cyr02full на CPU. Строки связаны с областями на изображении и доступны для ручного исправления.
- Дополнительные встроенные CRNN-модели для церковнославянского и «Проста мова».
- Исторические графические наблюдения, локальный поиск в корпусном материале и морфологический разбор доступными UDPipe-моделями.
- История анализов, локальная база данных, экспорт результатов и поиск библиографических записей через OpenAlex/Crossref.

Все результаты распознавания и автоматического анализа следует сверять с изображением и научными публикациями. Точность OCR на разных почерках этой версией не установлена; распознанный текст можно исправлять вручную. Правила охватывают только ограниченный набор графических признаков, а не полную историческую грамматику. Для некоторых периодов и традиций морфологическая модель отсутствует — интерфейс сообщает об этом вместо выдуманного разбора. Библиографический поиск возвращает метаданные публикаций, а не проверенные цитаты.

**Автоматический переводчик в этом выпуске отключён.** Приложение не выдаёт исходный текст или машинную догадку за перевод. Исследовательские корпуса и экспериментальные веса перевода не включены в установщик.

Пользовательские сканы и история сохраняются в `~/Library/Application Support/Палеослов`; выпуск не изменяет исходные файлы. Удаление приложения не удаляет эту папку.

## Исходный код и разработка

Исходный код и инструкции по сборке находятся в этом репозитории. Готовый автономный установщик размещён в GitHub Releases. Текущий проект рассчитан на Apple Silicon; выпуск для Intel Mac не собирался.

```sh
python3.12 -m venv --copies .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m pytest
```

См. [SOURCES.md](SOURCES.md) и [LICENSES.md](LICENSES.md) для происхождения и лицензий включённых компонентов. На код приложения отдельная открытая лицензия не выдана.
